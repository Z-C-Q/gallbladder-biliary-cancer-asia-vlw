# Data directory

- `processed/` contains the minimum study-specific processed inputs required by the public analysis workflow.
- `external/` contains the World Bank World Development Indicators extract used in the valuation framework.
- `raw/` contains access and filename instructions only; source-level IHME downloads are not redistributed.

See `DATA_DICTIONARY.md`, `DATA_AVAILABILITY.md`, and `LICENSES/DATA_LICENSES.md` for definitions, provenance, and reuse terms.
