# Draft response to the editor

Thank you for highlighting the Cell Press resource-availability and data-sharing requirements. We have prepared a public reproducibility repository containing the analytical input datasets required to reproduce the study, the complete original R workflow, and documentation of data sources, variable definitions, licensing, and reproducibility. The repository is available at https://github.com/Z-C-Q/gallbladder-biliary-cancer-asia-vlw and the version used for the revised manuscript is archived at https://doi.org/10.5281/zenodo.22133469.

The study uses secondary aggregate GBD 2023, HALE, SDI, and World Bank economic data and does not generate a standardized experimental data type requiring a data-type-specific accession number. Source-level GBD and HALE downloads are governed by IHME access and use terms and are therefore not redistributed as unrestricted raw files. We provide the exact source specifications, filenames, minimum processed inputs, and scripts needed to regenerate the processed data after users obtain the source files under the applicable IHME agreement. World Bank source attribution and license information are included in the repository.

We have updated the Resource availability section and Key resources table accordingly.
